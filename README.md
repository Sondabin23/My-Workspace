# AI 인구정보 분석 시스템

대학교 과제용 Python + Streamlit 프로그램입니다. CSV를 Python으로 분석한 뒤,
요약 통계만 ChatGPT 또는 Gemini에 전달하여 해석과 보고서를 만듭니다.
API 키가 없는 **시연 모드**는 Python 통계로 기본 보고서를 만들며 AI 결과와 구분합니다.

## 1. 프로젝트 구조

```text
population_ai_project/
  app.py                  # 화면, 그래프, 세션 캐시, 실행 순서
  config.py               # 경로, 연령층, 임의 지표 기준, 환경변수
  data_analysis.py        # 인코딩/열 탐색, 숫자 검증, 통계
  ai_analysis.py          # 두 API 연결, 프롬프트, 시연용 분석
  report_generator.py     # 통계표와 해석 결합, 안전한 HTML
  requirements.txt
  .env                    # 빈 키만 포함. 직접 설정
  .env.example
  .gitignore
  data/age.csv            # 제공받은 실제 CSV
  tests/test_project.py   # 통계, 잘못된 CSV, UI, API 모의 테스트
```

## 2. 동작 과정

CSV 읽기 → 월/성별 계열 확인 → 지역 검색/선택(1~5개) → 분석 실행 →
통계·자동 인사이트·그래프 → AI 분석 및 보고서 생성 → 다운로드 → 추가 질문.

CSV는 UTF-8-SIG, UTF-8, CP949, EUC-KR 순으로 읽습니다. UTF-8-SIG는 BOM 없는
UTF-8도 읽을 수 있으므로 이때 표시되는 인코딩도 UTF-8-SIG일 수 있습니다.
지역명 후보와 연령 열 정규식으로 데이터 구조를 찾습니다. 연령 열은 0세부터
65세 이상까지 연속된 단일 나이 열이어야 합니다. '100세 이상' 같은 마지막 구간을 지원합니다.
여러 월이나 남/여/총계 열이 함께 있으면 **데이터 계열**에서 고릅니다.
인구수는 쉼표를 제거한 후 숫자로 변환하며 빈 셀, 잘못된 문자, 음수, 소수는
0명으로 바꾸지 않고 해당 지역 분석을 차단합니다. 총인구와 연령 합계도 검증합니다.

시·구·동은 CSV의 각 행을 그대로 분석합니다. 부모 지역과 자식 지역을 더하면
중복되므로 선택 지역 합계는 만들지 않습니다. 동일한 동 이름은 전체 행정구역명과
코드로 구별합니다. 원본에 없는 시 단위 합계를 임의로 만들지 않습니다.

## 3. 필요한 라이브러리

Streamlit(화면), Pandas(CSV/표), NumPy(계산), Matplotlib(그래프),
openai(Responses API), google-genai(Gemini), python-dotenv(.env),
Markdown(HTML 변환), bleach(HTML 정리). PDF 라이브러리는 필수가 아닙니다.

## 4. Windows 설치

Python 3.11 이상(권장 3.12)을 설치하고 프로젝트 폴더에서 PowerShell을 엽니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

가상환경을 사용하지 않을 때는 다음 명령도 가능합니다.

```powershell
pip install -r requirements.txt
```

라이브러리 설치에는 인터넷이 필요합니다. 실제로 검증한 라이브러리 버전은
같이 제공된 `테스트결과.md`에서 확인할 수 있습니다.

## 5. API KEY 설정

빈 `.env`가 포함되어 있습니다. 파일이 없으면 다음과 같이 만듭니다.

```powershell
Copy-Item .env.example .env
notepad .env
```

```env
OPENAI_API_KEY=여기에_발급받은_키
GEMINI_API_KEY=여기에_발급받은_키

```

사용할 서비스의 키만 설정하면 됩니다. API 키는 OpenAI 개발자 플랫폼 또는
Google AI Studio에서 발급받으세요. 모델 이름은 계정에서 이용 가능한 모델로
바꿀 수 있고 화면에서도 바꿀 수 있습니다. 위 이름은 기본 설정이지 모델 이용을
보장하는 값이 아닙니다. ChatGPT 웹 구독과 API 사용 설정은 별도로 확인하세요.
.env 변경 후 Streamlit 프로세스를 종료하고 재실행합니다.
키를 소스 코드·스크린샷·과제 제출 ZIP에 넣지 마세요. 빈 키인 상태로 제출하세요.

공식 SDK 참고:
- [OpenAI Python API](https://developers.openai.com/api/reference/python)
- [Google Gen AI Python SDK](https://github.com/googleapis/python-genai)

## 6. 실행 방법

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py
```

또는 설치한 Python 환경에서:

```powershell
streamlit run app.py
```

브라우저의 `http://localhost:8501`에서 사용할 수 있습니다.
CSV 업로드를 생략하면 `data/age.csv`를 자동으로 읽습니다.

시연 순서:
1. AI 서비스를 '시연 모드'로 둡니다.
2. 지역 검색에 '안산'을 입력하고 지역 1~5개를 선택합니다.
3. '분석 실행'을 눌러 카드, 그래프와 표를 확인합니다.
4. '기본 보고서 생성'을 눌러 Markdown/TXT/HTML을 다운로드합니다.
5. API 시연은 ChatGPT/Gemini를 고르고 'AI 분석 및 보고서 생성'을 누릅니다.
6. 보고서 생성 후 추가 질문을 보냅니다. 추가 질문마다 현재 지역 요약만 전달하며,
   앞선 대화 전체는 보내지 않습니다. 질문은 독립적으로 작성하세요.

## 7. 분석 기준과 주의할 해석

- 유소년 0~14세, 청년 15~29세, 중년 30~49세, 장년 50~64세, 노년 65세 이상.
- 중장년은 중년 + 장년(30~64세), 생산가능인구는 15~64세입니다.
- 비율 = 해당 인구 / 연령별 합계 × 100. 노년 비율과 고령화 비율은 같습니다.
- 평균연령 = Σ(나이 × 인구수) / 총인구. 100세 이상은 100세로 대입하므로
  실제 평균의 하한 추정치입니다. 마지막 열이 100세 단일 나이면 해당 나이를 사용합니다.
- 최대/최소 연령 구간은 동률을 모두 표시합니다. 최소값 계산에 0명도 포함합니다.
- 최대/최소 연령층은 구간 길이가 다르므로 단일 연령별 최대와 구분하세요.
- 고령화 지표: 14% 미만 낮음, 14~20% 미만 보통, 20% 이상 높음.
- 청년 지표: 15% 미만 낮음, 15~25% 미만 보통, 25% 이상 높음.
- 위 지표는 **과제 시연용 임의 기준**이며 공식 위험 등급이나 전국 평균이 아닙니다.
  수정 위치는 `config.py`의 `AGING_THRESHOLDS`, `YOUTH_THRESHOLDS`입니다.
  기준을 바꾸면 `app.py`, `report_generator.py`의 설명 문구도 함께 고치세요.
- 이 CSV 헤더의 기준은 **2020년 9월**입니다. 보고서 작성일과 자료 기준월을
  별도로 표시하며 현재 인구로 해석하지 않습니다.
- 한 시점의 연령 분포로 이주, 인구 증감, 직업, 실제 시설 부족, 미래 수요를
  확정할 수 없습니다. AI 프롬프트는 없는 사실을 만들지 말도록 요청하지만
  모델이 이를 완벽하게 지킨다는 보장은 없으므로 해석은 검토해야 합니다.

## 8. 보고서와 PDF

Markdown과 TXT는 같은 보고서 본문을 저장합니다(TXT에도 표의 Markdown 문법이 남습니다).
HTML에는 모든 그래프가 이미지로 내장되어 인터넷 없이 열 수 있습니다.
PDF는 선택 기능입니다. HTML을 Edge/Chrome으로 열고 `Ctrl+P`에서
'PDF로 저장'을 선택하세요. Python에서 직접 PDF를 생성하는 기능은 포함하지 않았습니다.

## 9. API 비용과 오류 처리

AI에는 요약 통계와 자동 인사이트만 전달합니다. 원본 CSV, 전체 연령별 행,
키는 프롬프트에 보내지 않습니다. 분석/보고서 버튼을 눌러야 API를 호출합니다.
성공한 같은 통계·제공자·모델 응답과 같은 추가 질문은 사용자 세션에서 캐시합니다.
프로그램 재시작이나 새 세션에서는 캐시가 사라집니다. 자동 재시도는 끕니다.
오류 응답을 캐시하지 않아 다시 요청할 수 있습니다.

파일 없음, 인코딩, 빈 데이터, 비정상 숫자, 합계 불일치, 검색 결과 없음,
API 키 없음, 네트워크/할당량/API 오류, 빈/잘린/잘못된 AI 응답에 안내를 표시합니다.
제공자 서버의 오류 원문은 인증 정보 노출을 피하려고 화면에 출력하지 않습니다.
API 실패 후에도 통계와 그래프는 유지되며 시연 모드 보고서를 만들 수 있습니다.

## 10. 테스트 방법

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

자동 테스트는 실제 CSV의 합계·서울 인구, 경계 연령층·평균·동률,
다중 계열, 숫자/인코딩 오류, 합계 불일치, 빈 데이터, HTML 정리,
API 모의 응답/실패, Streamlit 화면의 기본 분석과 보고서 생성을 확인합니다.
실제 API를 호출하지 않으므로 비용이 발생하지 않습니다.

수동 테스트:
1. 서울특별시 한 지역, 안산/수원/서울 다지역을 각각 분석합니다.
2. 한글 그래프와 통계표의 인구수/비율을 확인합니다.
3. 존재하지 않는 지역 검색, 지역 미선택, 최대 5개 선택을 확인합니다.
4. 잘못된 CSV(빈 셀, 문자, 음수)를 업로드하여 오류 안내를 확인합니다.
5. 부모 시와 자식 구를 선택해 인구 합계가 생기지 않는지 확인합니다.
6. 보고서 생성 후 지역/계열/모델을 바꿔 이전 결과가 섞이지 않는지 확인합니다.
7. 키 없이 ChatGPT를 선택해 통계는 동작하고 API 요청은 안내로 처리되는지 확인합니다.
8. 실제 키를 설정해 두 제공자의 분석·추가 질문을 각각 확인합니다.
9. HTML에서 한글·그래프·표가 보이고 인쇄하여 PDF로 저장되는지 확인합니다.

## 11. CSV 구조가 다를 때 수정 위치

실제 제공된 CSV는 `행정구역`, `2020년09월_계_총인구수`,
`2020년09월_계_연령구간인구수`, `2020년09월_계_0세` …
`2020년09월_계_100세 이상` 형태입니다. 기본 상태에서 수정 없이 지원합니다.
`연령구간인구수`는 개별 연령이 아니므로 중복 합산하지 않습니다.

다른 형식의 파일은 `data_analysis.py`의 다음 위치를 수정하세요.
- `discover_schema`: 지역명 후보, 연령 정규식, 계열 접두사, 총인구 후보.
- `read_csv_bytes`: 구분자가 탭/세미콜론일 때 `pd.read_csv`의 `sep` 설정.
- `load_data`: 기준월 추출 정규식 및 숫자 전처리.
- 0~9세처럼 구간으로만 나뉜 파일은 단일 연령 통계(평균/최대 나이)를 정확히
  계산할 수 없으므로 현재는 거부합니다. 구간을 임의로 단일 나이로 나누지 마세요.
- 한국어가 아닌 헤더, 여러 메타데이터 행, 불명확한 지역 열, 행 중복,
  연령 누락은 원본을 정리하거나 위 함수를 명시적으로 수정하세요.

과제 설명의 핵심: CSV 로딩/검증 → 순수 통계 함수 → API 해석 → 보고서 조합을
파일별로 분리했습니다. 화면에서 선택을 바꾸면 재분석해야 하고,
보고서는 정확한 Python 통계표와 검토가 필요한 AI 해석을 함께 보여줍니다.

## 12. Render 웹 배포

`render.yaml`은 무료 Python 웹 서비스, 싱가포르 리전, 0.0.0.0:$PORT 바인딩,
Streamlit 헬스체크를 설정합니다. `.python-version`은 Python 3.12를 선택하고
`constraints-render.txt`는 자동 테스트한 직접 의존성 버전을 고정합니다.
`fonts/NanumGothic-Regular.ttf`는 Linux에서 한글 그래프를 표시하기 위한 폰트이며
같은 폴더의 `OFL.txt` 라이선스로 배포합니다.

서비스를 만들 때 빌드 명령은 다음과 같습니다.

```bash
pip install -r requirements.txt -c constraints-render.txt && python setup_assets.py
```

시작 명령:

```bash
python -m streamlit run app.py --server.address=0.0.0.0 --server.port=$PORT
```

API 키는 저장소에 업로드하지 않습니다. 기본 웹 시연은 키 없이 사용할 수 있습니다.
실제 AI를 사용하려면 Render 서비스의 Environment에 `OPENAI_API_KEY` 또는
`GEMINI_API_KEY`를 추가하세요. 환경변수가 `.env`보다 우선합니다.
무료 서비스는 일정 시간 사용하지 않으면 절전 상태로 들어가 첫 접속이 느릴 수 있습니다.
Git 저장소에는 원본과 동일한 CSV를 `data/age.csv.gz`로 압축하여 넣고 빌드 때 풀어 사용합니다.
서버용 폰트도 빌드 때 Google Fonts의 공식 저장소에서 받습니다.
